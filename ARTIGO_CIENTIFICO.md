# PDF para HTML Vivo: Conversor Local para HTML5 Semântico WCAG 2.2 AA

## Resumo
O **PDF para HTML Vivo** converte texto extraído de documentos PDF em HTML5 semântico acessível para leitores de tela, 100% no navegador.

## Validação
Suíte automatizada (`npm test`) aprovada.
